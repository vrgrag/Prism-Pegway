# Prism Pegway — Audio assets

The game references the audio files listed below. To keep the repository free of
material with unclear licensing, **no audio binaries are bundled**. The game is
built to run without them (missing files are ignored gracefully by the
`AudioManager`). Drop royalty-free `.ogg`/`.mp3` files with these exact names to
enable sound.

Recommended sources: Kenney.nl, OpenGameArt (CC0), Freesound (CC0), Pixabay.

## Music (looping)
- `music_menu.ogg`      — calm futuristic main-menu theme
- `music_gameplay.ogg`  — light ambient gameplay loop

## One-shot SFX
- `sfx_complete.ogg`  — level complete fanfare
- `sfx_fail.ogg`      — level failed
- `sfx_crystal.ogg`   — crystal pickup
- `sfx_bounce.ogg`    — ball bounces off a peg/wall
- `sfx_booster.ogg`   — booster pad engaged
- `sfx_spring.ogg`    — spring launch
- `sfx_magnet.ogg`    — magnet hum
- `sfx_prism.ogg`     — prism redirect
- `sfx_teleport.ogg`  — teleporter warp
- `sfx_click.ogg`     — UI click
- `sfx_place.ogg`     — object placed
- `sfx_launch.ogg`    — simulation launched
